# QwenChat

Нативный iOS-чат на SwiftUI для API DashScope (Alibaba Cloud) — со стримингом ответов,
веб-поиском и чтением ссылок. Работает без мака, бэкенда и App Store:
сборка происходит в GitHub Actions, установка — через SideStore.

## Возможности

- Чат со стримингом ответа (токен за токеном), markdown
- Прямые запросы к DashScope с телефона (OpenAI-совместимый endpoint)
- Веб-поиск через `enable_search` + инструмент `read_url` для чтения страниц
- История чатов локально на устройстве, ключ — в Keychain

## Шаг 1. Запушить в GitHub

Создай на GitHub пустой репозиторий (можно приватный, минут Actions хватит),
затем в папке проекта:

```
git init
git add .
git commit -m "QwenChat"
git branch -M main
git remote add origin https://github.com/ТВОЙ_ЛОГИН/QwenChat.git
git push -u origin main
```

## Шаг 2. Скачать собранный .ipa

1. Открой репозиторий → вкладка **Actions** → дождись зелёной галочки у `Build IPA`
2. Внизу страницы сборки скачай артефакт **QwenChat-ipa**
3. Распакуй zip — внутри `QwenChat.ipa`

## Шаг 3. Установить SideStore (один раз, нужен кабель)

1. Установи на ПК **iTunes** и **iCloud** с сайта apple.com (НЕ из Microsoft Store)
2. Скачай установщик SideStore: https://sidestore.io и следуй его инструкции
3. Подключи iPhone **кабелем**, разблокируй, нажми «Доверять»
4. После установки SideStore сгенерируй pairing-файл (по инструкции SideStore, тоже по кабелю) и включи WireGuard VPN

Подробная документация: https://docs.sidestore.io

## Шаг 4. Установить приложение

1. Перекинь `QwenChat.ipa` на телефон (Saved Messages в Telegram, iCloud Drive, почта)
2. На телефоне: **SideStore → My Apps → +** → выбери файл → введи свой Apple ID
3. Готово, иконка появится на домашнем экране

## Шаг 5. Настройка

В приложении: шестерёнка → вставь API-ключ DashScope.
- Модель по умолчанию: `qwen-plus` — поменяй на ту, что доступна твоему ключу
- Если приходит ошибка про `enable_search` — выключи тумблер веб-поиска

## Важно знать

- Подпись бесплатного Apple ID живёт **7 дней**. SideStore обновляет её автоматически
  при включённом VPN — просто открывай SideStore раз в несколько дней.
- Лимит бесплатного аккаунта — 3 приложения одновременно.
- Чтобы обновить приложение после правок: `git push` → Actions соберёт новый `.ipa` →
  установи его в SideStore поверх старого. История чатов сохранится.
